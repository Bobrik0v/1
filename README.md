# 3D-JET.by — сайт мастерской 3D-печати в Минске

Одностраничный лендинг: 3D-печать, сканирование, моделирование, ремонт
мелкой бытовой техники (скоро), гид по материалам, цены и форма заявки.
Чистый HTML/CSS/JS — без сборки и зависимостей.

## Структура

- `index.html` — вся разметка страницы (тексты меняются здесь)
- `css/style.css` — стили (основной цвет — переменная `--accent` в начале файла)
- `js/main.js` — мобильное меню и обработка формы

## Как посмотреть

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000

## Форма заявки

Форма отправляет заявки на почту через [Web3Forms](https://web3forms.com/).

- Адрес API `https://api.web3forms.com/submit` задан в атрибуте `action`
  формы `contactForm` в `index.html`.
- Публичный `access_key` находится в скрытом поле этой формы в `index.html`.
  Он связан с получателем заявок в Web3Forms и предназначен для использования
  в клиентском коде.
- `js/main.js` читает поля из HTML через `FormData` и отправляет их на
  `form.action`, затем показывает сообщение об успехе или ошибке.
  Сам ключ в JavaScript не хранится.
- Поля заявки: `name`, `phone`, `message`. Для базовой защиты от ботов
  добавлено скрытое поле `botcheck`.

FormSubmit больше не используется; подтверждать почту в нём не требуется.
